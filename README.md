# Telegram Demo/Test Bot

Free-oriented Telegram bot structure:
Start → user photo → reference clothes photo → Change Clothes → 2 private channel links → Verify → demo processing → demo token-limit message.

Set `BOT_TOKEN` as a Render environment variable. Never put the BotFather token in source code.

The bot is explicitly a Demo/Test Bot and does not generate or return an actual clothes-change result.
